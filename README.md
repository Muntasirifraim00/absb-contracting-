# Pixel Perfect Design

এখানে চারটা ছবি। লিখা বলা যেই ছবিটা রয়েছে সেটাই তোমাকে accurate বানাতে হবে। mobile view টা mobile view এর জন্য এবং desktop view টা desktop view এর জন্য। তুমি খালি ছবিগুলোর উপর সরাসরি লেখাগুলো একদম accurate position প্রতিটা icon, প্রতিটা লেখা, প্রতিটা button এরা position accurate রেখে তুমি এই design টা বানাও। দেখবে সম্পূর্ণ ছবির মতোই তুমি এটা বানাতে পেরেছ
